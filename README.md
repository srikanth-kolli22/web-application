# Running the Application

1.  Open the extracted project folder in Visual Studio Code.

2.  Open the VS Code terminal (**Terminal → New Terminal**).

3.  Run the following command to install the project dependencies:

    ``` bash
    npm install
    ```

4    npx playwright install chromium


5  After the installation is complete, start the application:

    ``` bash
    npm start
    ```

6.  Open the local URL shown in the terminal in your web browser.

**Note:** Keep the terminal open while using the application. Press
`Ctrl + C` in the terminal when you want to stop the application.
